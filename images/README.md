| File                      | Category             |
|---------------------------|----------------------|

Notes:
- Landscape, roughly 1600×1000 or wider. They are cropped with
  `object-fit: cover`, so keep the subject near the centre.
- They are rendered desaturated to match the black-and-white palette,
  so contrast matters more than colour.
- If a file is missing the site falls back to the illustration for that
  category — nothing breaks.
